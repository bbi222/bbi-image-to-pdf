## 한국어

설치·가입 없이 브라우저에서 이미지를 **원하는 위치와 크기로 배치해** PDF로 만드는 무료 도구예요.
이미지는 서버로 올라가지 않고, 내 기기 안에서만 처리돼요.

👉 **바로 쓰기:** https://bbi222.github.io/bbi-image-to-pdf/

### 주요 기능
- JPG · PNG · WEBP 여러 장 추가 (끌어놓기, 붙여넣기 지원)
- 페이지 위에서 이미지 이동·크기 조절·회전
- 용지 A4 / Letter / 이미지 크기에 맞춤, 방향·여백 설정
- 한 페이지에 1·2·4·6·9장 격자 배치, 칸 간격 설정
- 세로·가로로 긴 이미지를 여러 페이지로 나누기
- 눈금자(mm·cm·inch·pt), 안내선, 스냅(자석 정렬), 정렬 버튼
- 되돌리기/다시 실행, 확대·축소, 화면 이동
- 한국어 / English 전환

### 사용법
1. [이미지 추가] 또는 끌어다 놓기
2. [페이지] 탭에서 용지·방향·여백 설정
3. 이미지를 끌어 위치·크기 조절
4. [PDF 만들기]

### 단축키
| 키 | 동작 |
|---|---|
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Ctrl+C / Ctrl+V | 이미지 복사 / 붙여넣기 |
| Ctrl + 휠 | 확대·축소 |
| Space + 끌기 | 화면 이동 |
| Alt + 끌기 | 스냅 끄기 |

| Delete | 선택 삭제 |

## English

A free browser tool that turns images into a PDF with **layout you control**: no install, no sign-up.
Images never leave your device; everything runs locally in your browser.

👉 **Use it now:** https://bbi222.github.io/bbi-image-to-pdf/

### Features
- Add multiple JPG / PNG / WEBP images (drag & drop, paste)
- Move, resize and rotate images on the page
- Paper: A4 / Letter / fit to image; orientation and margins
- Grid layout of 1 / 2 / 4 / 6 / 9 images per page, adjustable gap
- Split a very tall or wide image across several pages
- Rulers (mm / cm / in / pt), guides, snapping, align buttons
- Undo / redo, zoom, pan
- Korean / English UI

### How to use
1. Click **Add images** or drag them in
2. Set paper, orientation and margins in the **Page** tab
3. Drag images to position and resize
4. Click **Make PDF**

### Shortcuts
| Keys | Action |
|---|---|
| Ctrl+Z / Ctrl+Y | Undo / redo |
| Ctrl+C / Ctrl+V | Copy / paste image |
| Ctrl + wheel | Zoom |
| Space + drag | Pan |
| Alt + drag | Disable snapping |
| Shift + drag | Lock to one axis |
| Delete | Delete selected |

### Privacy
No uploads. All processing happens in your browser; no data is sent anywhere.

### Run locally
Everything is in a single `index.html`. Download it and open it in a browser; it works offline.
